# Python Example Scripts

This directory contains practical Python scripts demonstrating key programming concepts.

## Running the Examples

Each script can be run independently:

```bash
python3 01_hello_world.py
python3 02_variables_and_types.py
# ... and so on
```

Or make them executable and run directly:

```bash
chmod +x 01_hello_world.py
./01_hello_world.py
```

## Examples Overview

### 01_hello_world.py
Your first Python program! Demonstrates basic print statements and string formatting.

**Concepts:** Print statements, string formatting, basic program structure

### 02_variables_and_types.py
Learn about different data types in Python including numbers, strings, booleans, and None.

**Concepts:** Variables, integers, floats, strings, booleans, type conversion

### 03_control_structures.py
Master control flow with if-else statements, loops, and flow control.

**Concepts:** If-else, for loops, while loops, break, continue

### 04_functions.py
Understand how to create and use functions, including parameters and return values.

**Concepts:** Function definition, parameters, return values, lambda functions, recursion

### 05_data_structures.py
Work with Python's built-in data structures: lists, tuples, dictionaries, and sets.

**Concepts:** Lists, tuples, dictionaries, sets, comprehensions, data manipulation

### 06_oop.py
Introduction to Object-Oriented Programming with classes, objects, and inheritance.

**Concepts:** Classes, objects, methods, encapsulation, inheritance, polymorphism

### 07_file_handling.py
Learn to read and write files, with proper error handling.

**Concepts:** File I/O, reading, writing, appending, exception handling

## Tips

1. **Read the code first** - Understand what each script does before running it
2. **Modify and experiment** - Change values and see what happens
3. **Add your own code** - Try implementing similar functionality
4. **Break things** - Don't be afraid to make mistakes; they're learning opportunities
5. **Use comments** - Add your own comments to explain your understanding
