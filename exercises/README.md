# Python Practice Exercises

This directory contains hands-on coding exercises to practice your Python skills.

## How to Use These Exercises

1. **Read the exercise file** - Each file contains TODO comments and function stubs
2. **Implement the functions** - Replace `pass` with your own code
3. **Test your solution** - Run the file to see if your implementation works
4. **Check the solution** - Compare with the solutions in the `solutions/` directory
5. **Try the challenges** - Each exercise has additional challenge problems

## Exercises List

### Exercise 1: Calculator (`exercise_01_calculator.py`)
**Level:** Beginner  
**Topics:** Functions, user input, basic arithmetic, error handling

Create a simple calculator that can perform basic mathematical operations.

### Exercise 2: List Operations (`exercise_02_list_operations.py`)
**Level:** Beginner  
**Topics:** Lists, list methods, iteration, algorithms

Practice common list operations like finding min/max, removing duplicates, and counting occurrences.

### Exercise 3: String Manipulation (`exercise_03_string_manipulation.py`)
**Level:** Beginner  
**Topics:** Strings, string methods, text processing

Work with strings to count vowels, check palindromes, reverse words, and more.

### Exercise 4: Dictionary Practice (`exercise_04_dictionaries.py`)
**Level:** Beginner to Intermediate  
**Topics:** Dictionaries, key-value pairs, data management

Use dictionaries to manage student records, calculate averages, and merge data.

### Exercise 5: Object-Oriented Programming (`exercise_05_oop.py`)
**Level:** Intermediate  
**Topics:** Classes, objects, methods, encapsulation

Create classes to model real-world objects like rectangles, bank accounts, and students.

## Tips for Success

1. **Start Simple** - Begin with the basic requirements before attempting challenges
2. **Test Incrementally** - Test each function as you write it
3. **Use Print Statements** - Debug by printing intermediate values
4. **Read Error Messages** - They often tell you exactly what's wrong
5. **Try Different Inputs** - Test with various inputs including edge cases
6. **Don't Peek Too Soon** - Try solving on your own before looking at solutions
7. **Understand, Don't Memorize** - Focus on understanding the logic

## Testing Your Solutions

Run any exercise file directly:

```bash
python3 exercise_01_calculator.py
```

## Challenge Yourself

After completing the basic exercises:

2. Add additional features and error handling

5. Create your own variations of these exercises

## Getting Help

If you're stuck:
1. Review the relevant section in `python_basics.md`
2. Check the corresponding example in the `examples/` directory
3. Look at the solution for hints (but try first!)
4. Break the problem into smaller parts
5. Search for Python documentation online

Remember: Struggling is part of learning! Keep practicing! 🚀
